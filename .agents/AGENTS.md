# MySmartHub — Project Rules & Guidelines

Dokumen ini berisi 5 rules utama yang wajib diikuti saat mengembangkan project **MySmartHub**.
Project ini adalah aplikasi Personal Productivity Hub berbasis PHP + MySQL yang berjalan di Laragon.

Detail lengkap setiap rule ada di file terpisah:

| No | Rule                  | File                                     | Deskripsi                                              |
|----|-----------------------|------------------------------------------|--------------------------------------------------------|
| 1  | Architecture Rule     | `docs/rules/01_architecture.md`          | Struktur folder, prinsip module-first & separation     |
| 2  | Design Rule           | `docs/rules/02_design.md`               | Design system, color palette, dark mode, responsif     |
| 3  | PRD Rule              | `docs/rules/03_prd.md`                  | Daftar fitur MVP, prioritas, format user story         |
| 4  | Coding Rules          | `docs/rules/04_coding.md`               | PHP/JS standards, security, naming convention          |
| 5  | Schema Rule           | `docs/rules/05_schema.md`               | Konvensi database, relasi tabel, aturan migrasi        |

---

*Rules ini dikelola oleh tim MySmartHub. Update rules harus melalui review dan persetujuan sebelum diterapkan.*
