# Rule 3 — PRD Rule (Product Requirements Document)

## Fitur Inti yang Wajib Ada (MVP)

| No | Modul          | Status    | Deskripsi Singkat                                  |
|----|----------------|-----------|----------------------------------------------------|
| 1  | Auth           | Done      | Register, Login, Logout dengan session PHP         |
| 2  | Dashboard      | Done      | Overview stats: todo, event, pengeluaran           |
| 3  | Task / Todo    | WIP       | CRUD todo dengan prioritas, status, deadline       |
| 4  | Notes          | Planned   | CRUD catatan dengan rich text & kategori           |
| 5  | Calendar       | Planned   | Manajemen event dengan tampilan kalender bulanan   |
| 6  | Finance        | Planned   | Pencatatan pemasukan & pengeluaran + grafik        |
| 7  | Habits         | Planned   | Habit tracker harian dengan streak & log           |
| 8  | AI Assistant   | Planned   | Chat AI berbasis Gemini API untuk produktivitas    |
| 9  | Notifications  | Planned   | Notifikasi in-app untuk pengingat deadline         |
| 10 | Profile        | Planned   | Edit profil, foto, ubah password, pengaturan tema  |

## Prioritas Pengembangan

1. Selesaikan modul **Task** (CRUD lengkap + filter + kategori)
2. Modul **Notes** dengan fitur pin & kategori
3. Modul **Finance** dengan chart pemasukan vs pengeluaran
4. Modul **Calendar** dengan tampilan bulan
5. Modul **Habits** + **AI Assistant** sebagai fitur premium

## User Story Standar

Setiap fitur baru wajib memenuhi format user story:
> "Sebagai [user], saya ingin [aksi], sehingga [manfaat]."

Contoh: "Sebagai user, saya ingin menambah todo dengan deadline, sehingga saya bisa mengatur prioritas pekerjaan."
